## Universal Dynamic Tooltip
- **Goal**: Create a highly responsive, dynamic tooltip component that will be used universally across the site.
- **Purpose**: To make all interactive elements feel alive, snappy, and responsive.
- **Details**: 
  - Needs to track mouse position or anchor smoothly.
  - Smooth enter/exit animations (framer-motion or CSS transitions).
  - Reusable across project cards, buttons, graphs (like the GitHub commit graph), and inline links.
  - The content inside the the tooltop be really dynamic, I can show text, even formatted, or even images if I wanted to
  - the tooltip basically just acts as an universal wrapper while each hoverable piece of UI has it's own component element that will appear inside the tooltip wrapper
