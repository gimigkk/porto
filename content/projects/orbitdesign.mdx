## Collaborative Prototyping

OrbitDesign is a web-based canvas that allows distributed teams to work together on wireframes and UI sketches without the friction of heavy design software.

### Key Features
- **Real-time collaboration**: Powered by WebSockets in Node.js.
- **Figma Integration**: Import assets directly from your Figma files.
- **Infinite Canvas**: Built in React with highly optimized rendering for complex diagrams.
