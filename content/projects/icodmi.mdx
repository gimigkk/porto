## The Problem

The original website for ICoDMI (International Conference on Data Science, Mathematics, and Informatics) had some responsiveness issues - it wasn't usable on mobile devices. Visually, it also looked a bit generic and didn't quite fit the feel of an international academic conference.

We came in to fix the mobile layout and clean up the UI without drifting away from their existing brand guidelines, even though we weren't the original lead developers.

## Approach

### UI/UX Updates

We focused on cleaning up the design while keeping the core identity intact. We replaced the generic layouts with clearer typography and better spacing. We kept the original color palette exactly the same, but arranged things to make the site look more put-together.

### Mobile Optimization

The main priority was getting the site to work well on phones. We rebuilt the layout structure so things fit properly across different screen sizes. The navigation, schedules, and speaker cards were updated to stack neatly on smaller screens.

### Using Astro

This was our first time using Astro, and it turned out to be a great choice for a landing page. It made building a fast, static site pretty straightforward. The component system also made it easy to keep the new design consistent across all pages.

## Outcome

The final result is a clean, responsive landing page that works well for the ICoDMI conference. The site is easy to use on mobile, and the overall design feels much more cohesive.

## Masalahnya

Website awal untuk ICoDMI (International Conference on Data Science, Mathematics, and Informatics) punya beberapa masalah responsivitas - halamannya nggak bisa dipakai dengan baik di HP. Secara visual, tampilannya juga agak generik dan kurang pas buat acara konferensi akademik internasional.

Tugas kita di sini buat benerin layout mobile dan ngerapiin UI-nya tanpa keluar dari panduan *brand* mereka, walaupun awalnya kita bukan *lead developer* di project ini.

## Pendekatan

### Update UI/UX

Kita fokus bikin desainnya lebih rapi sambil tetep pertahanin identitas aslinya. Layout yang sebelumnya diganti dengan tipografi yang lebih jelas dan jarak antar elemen yang lebih pas. Palet warnanya tetep pakai yang lama, tapi elemen-elemennya disusun ulang supaya tampilannya lebih enak dilihat.

### Optimasi Mobile

Prioritas utamanya itu bikin websitenya nyaman dibuka di HP. Kita rombak struktur layout-nya supaya bisa nyesuain ke berbagai ukuran layar. Navigasi, jadwal konferensi, dan kartu pembicara disesuaikan biar rapi pas dilihat di layar kecil.

### Menggunakan Astro

Ini pertama kalinya kita nyoba pakai Astro, dan ternyata lumayan pas buat *landing page*. Framework ini bikin proses buat bikin website statis yang cepet jadi lebih gampang. Sistem komponennya juga ngebantu banget buat jaga desainnya tetep konsisten di semua halaman.

## Hasilnya

Hasil akhirnya berupa *landing page* yang rapi, responsif, dan pas buat nampung info konferensi ICoDMI. Websitenya sekarang nyaman dipakai di HP, dan desain keseluruhannya terasa lebih nyatu.
