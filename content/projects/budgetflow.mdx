## Overview

BudgetFlow is a personal finance tracker that turns raw spending data into visual insights. Users can set budgets, track goals, and receive smart alerts when they're approaching limits.

## Key Features

- **Visual analytics** — interactive charts that break down spending by category, time period, and trend
- **Smart alerts** — proactive notifications when spending patterns deviate from budgets
- **Goal tracking** — set savings targets and visualize progress with milestone celebrations
- **Firebase real-time sync** — data stays in sync across all devices instantly
